# ParishBSD-Container-Manager
Container Manager for ParishBSD project. Think of it as qubes-manager which is for QubesOS to manage qubes.

## Overview

ParishBSD Container Manager includes CLI and GUI tools. GUI is the frontend of CLI tools.

This source code is part of `parishbsd-compartments` package.
This tool allows to:
- Create new template(s)
- Destroy template(s)
- Create compartment based off template
- Manage Xpra connection.
- Manage pulse audio connection
- File exchange between compartment<->compartment, compartment<->vault, compartment<->host
- Vault management (lock/unlock)
- Vault lock scheduling
- Compartments risk management.
